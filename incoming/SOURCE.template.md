# SOURCE.md 模板 —— 照抄这一份，把空填掉

> 用法：把本文件复制成 `incoming/<mod 名字>/SOURCE.md`，逐条填空。
> **不要留空**；原件确实没有的信息，就明确写「原件未署名」「原件未声明许可」这类话。
> 写完可以删掉这一段与所有 `>` 开头的提示行。

## 1. 原件叫什么、从哪来

- **名称**：
- **来源**：（仓库 URL / 发布页 / 群文件；要能追溯）
- **版本或日期**：（有就写）
- **拿到的方式**：（直接下载的 zip？别人的 fork？群里的补丁？）

## 2. 原作者

- **署名**：（写不出名字就写「原件未署名」—— **不要自己填一个**）
- **联系方式**：（有就写，便于维护者确认授权）

## 3. 原件的许可

- **有没有 LICENSE**：（有就写文件名与许可名；没有就写「原件未声明许可」）
- **是否允许再分发**：（允许 / 不允许 / 不清楚）
- **其它限制**：（例如「仅限群内使用」「禁止商用」）

## 4. 它改了什么

尽量具体。改了哪些文件、哪些数据、哪些数值 —— 做成表最好：

| 改的东西 | 怎么改的 | 备注 |
|---|---|---|
| （例如 `data/backups.json` 的某条记录） | （例如 攻击力 500 → 620） | |
| | | |

- **有没有改引擎源码**：（有的话写清哪些文件）
- **有没有加新的干员 / 盟约 / 装备 / 特质**：
- **它自己说它做了什么**：（把原件 README 的说法摘一句，便于对照）

## 5. 自带素材是哪来的

| 素材 | 来源 | 授权 |
|---|---|---|
| （例如 2 张盟约徽记） | （同人自绘 / 从游戏解包 / 别人的作品） | （作者授权 / 无声明） |

- **是否夹带游戏官方素材**：（是 / 否。**是的话请不要把素材一起传上来**，
  只传改动说明与代码/数据部分 —— 见 [UPLOAD.md](../UPLOAD.md) 的红线）

## 6. 其它想说的

（例如：这个 mod 只在某个版本上能用；原作者已经停更；我知道它有哪部分大概做不成包……）
