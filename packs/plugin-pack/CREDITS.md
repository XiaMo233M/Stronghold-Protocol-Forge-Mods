## 本包与原件的关系（如实说明，不含任何夸大）

- 本包是原件 `E:\destop\卫戍协议-插件包-v0.2.1` 里**能由工坊包接口表达的那些件**的改写产物：
  客户端面板（`client.panels[]`）、自带样式表（`client.panels[].styles[]`）、
  给已有语种补的界面词条（`pack.json.i18n`）、鸣谢（`pack.json.notices`）。
- **逐件判定**（哪一件做到了、哪一件只做到一半、哪一件做不到以及缺什么接口）在
  `E:\destop\harness_1\_up\mod-compat\out\pluginpack-rewrite.md`，那里的每一条都带证据。
- **原件里「整份替换引擎文件」的那些件不在本包里，也不该在**：`shared/protocol.js`（wire 契约）、
  `shared/constants.js`（共享常量）、`server/lobby.js`（大厅本体）、`public/js/screens/game.js`（对局屏本体）
  都是**引擎**，按 `docs/MOD-SURFACE.md`「刻意不是表面的东西」不开放给包。
- 本包的 `client.panels[].module`（`ui/*.js`）**是照原件选择器与语义重写的模块**（原生 DOM，
  零额外依赖），**不含原件那些 preact 组件的字节** —— 因为包 import 不到引擎的 `components.js` /
  `vendor/preact.module.js`（`/workshop-panels/` 只服务本包自己的 URL）。
- 本包的 `css/plugin-pack.css` 是**照原件选择器重写**的一份自带样式表（`pp-` 前缀），
  **不是**原件那三份整份替换 CSS 的字节，也**不改引擎任何一个 CSS 文件**。
- 本包的 `i18n/{en,ja,ko,zh-TW}.json` **逐字节就是**原件 `④ i18n补丁/*.新增键.json`
  （74 键 × 4 语种）—— 由引擎的合并规则按事实处理（已有键绝不覆盖；`快速匹配` 值相同不计冲突、
  `语音语言` 在 en 是一条真冲突并被点名）。
- `pack.json` 的 `license` 是 `CC0-1.0`：本包不含原件那些**代码字节**的复制，也不含任何游戏素材
  （`assets/` 目录不存在）。原件的 `GPL-3.0` 是对**它自己那份代码与补丁**的声明；
  这里保留它的署名（上引 §7）是这一层的纪律，不是许可继承的声明。
